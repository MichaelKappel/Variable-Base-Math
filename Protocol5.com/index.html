What radix means

The alphabet used to write a number

Base 10 uses ten symbols, base 2 uses two, base 16 uses sixteen. The value can remain identical while the representation changes completely.

What the text tool is not

Not a substitute for standard cryptography

It is deterministic, inspectable, and portable, but it does not replace authenticated encryption, IVs, salts, or modern cryptographic hygiene.
