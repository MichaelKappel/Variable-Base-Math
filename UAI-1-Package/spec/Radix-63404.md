# Radix 63404
Version: radix-63404
Status: authoritative

## Definition

Base: 63,404

Alphabet:
- All Unicode BMP characters
- EXCLUDING:
  - whitespace
  - control characters
  - surrogate code units

Ordered by Unicode code point.

---

## Rules

- Each digit = ONE BMP character
- Digit value = index in ordered set
- No visual interpretation allowed

---

## Positional Value

value = Σ(digit × 63404^position)

---

## Forbidden

- glyph-based meaning
- linguistic interpretation
- visual inference
